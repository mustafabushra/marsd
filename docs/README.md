# فهرس توثيق مرصد

كل توثيق المشروع منظّم هنا. الجذر يحتوي فقط على `README.md` و `README_AR.md` و `RELEASE_NOTES.md`.

| المجلد | المحتوى |
|---|---|
| [product/](product/) | مواصفات المنتج، قواعد العمل، خارطة الطريق، رسم المعرفة |
| [architecture/](architecture/) | بنية المشروع، رموز التصميم، أفضل الممارسات، حزمة التقنيات |
| [guides/](guides/) | أدلة البدء والتطوير، إعداد قاعدة البيانات، حل المشكلات |
| [deployment/](deployment/) | النشر (Vercel / Docker / Railway)، المراقبة، قوائم الإطلاق |
| [testing/](testing/) | خطط الاختبار، حالات QA، تقارير E2E |
| [agents/](agents/) | نظام الوكلاء: التهيئة، التكامل، التوسعة |
| [archive/](archive/) | تقارير مراحل منتهية — مرجع تاريخي فقط، لا يُعتمد عليها |

## من أين أبدأ

- **جديد على المشروع؟** → [guides/START_HERE.md](guides/START_HERE.md) ثم [guides/DEVELOPMENT_GUIDE.md](guides/DEVELOPMENT_GUIDE.md)
- **تبي تفهم المنتج؟** → [product/MARSAD_PROJECT_SPEC.md](product/MARSAD_PROJECT_SPEC.md) و [product/BUSINESS_RULES.md](product/BUSINESS_RULES.md)
- **تبي تنشر؟** → [deployment/DEPLOYMENT_READY.md](deployment/DEPLOYMENT_READY.md) و [deployment/LAUNCH_CHECKLIST.md](deployment/LAUNCH_CHECKLIST.md)
- **إعداد قاعدة البيانات؟** → [guides/SETUP_DATABASE.md](guides/SETUP_DATABASE.md)

> **ملاحظة:** ملفات `archive/` كُتبت أثناء مراحل تطوير سابقة وقد لا تطابق الوضع الحالي للكود. اعتمد على الكود و `git log` كمصدر حقيقة.
