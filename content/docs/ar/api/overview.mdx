<Callout type="warning" title="ليست واجهة عامّة بعد">
النقاط أدناه دوالّ خادم تخدم واجهة مرصد نفسها. لا توجد مفاتيح API للمطوّرين،
ولا حدّ معدّل لكل مفتاح، ولا نسخ مُرقَّمة (`/v1/`). فهي موثَّقة هنا لأنها
موجودة، لا لأنها عُرضت للتكامل الخارجي.
</Callout>

## ما هو موجود

ستّ دوالّ تعمل على Vercel تحت `/api`. المجلّدات المسبوقة بـ`_` ليست نقاط
نهاية — `api/_lib` و`api/_report` وحدات مشتركة.

| الطريقة | المسار | الغرض | المصادقة |
|---|---|---|---|
| POST | `/api/scan-document` | فحص ملفّ في الحجر وترقيته | Clerk |
| POST | `/api/handoff-upload` | رفع من الهاتف عبر رمز QR | رمز في الطلب |
| POST | `/api/extract-document` | استخراج بيانات من صورة سجل | Clerk |
| POST | `/api/invite-user` | دعوة مستخدم إلى مستأجر | Clerk |
| GET | `/api/registry-source` | جلب بيانات من مصدر السجل | Clerk |
| GET | `/api/trust-report-pdf` | توليد تقرير ثقة PDF | Clerk |

## الأساس

جميع النقاط على النطاق نفسه الذي يخدم التطبيق:

```bash
https://marsd-peach.vercel.app/api/...
```

## الردود

الردّ JSON دائماً. والخطأ يحمل `error` بعبارة عربية جاهزة للعرض:

```json
{
  "error": "جلسة غير صالحة — أعد تسجيل الدخول"
}
```

وبعض النقاط تُضيف حقولاً تشخيصية: `reasons` و`messages` عند رفض ملفّ،
و`missingEnvVars` حين ينقص إعداد على الخادم.

## حدّ المعدّل

<Callout type="info">
`/api/scan-document` محدودةٌ بـ**١٢٠ طلباً في الساعة لكل حساب**. وعند التجاوز
يعود `429` مع ترويسة `Retry-After`.
</Callout>

الحدّ يُعدّ في القاعدة لا في ذاكرة الدالة: نسخة serverless تعيش دقائق وتعمل
متوازيةً، فعدّادٌ محلّي يبدأ من الصفر مع كل بداية باردة ويقول إنه يحدّ ولا يحدّ.

## ما ليس موجوداً

هذه غير منفَّذة، ولا تُوثَّق كأنها كذلك:

- **مفاتيح API** — المصادقة بجلسة Clerk فقط
- **Webhooks** — لا إرسال أحداث إلى أنظمة خارجية
- **نقاط قراءة للشركات أو التقارير** — القراءة تجري من العميل مباشرةً عبر
  Supabase مع RLS، لا عبر `/api`
- **ترقيم النسخ** — لا `/v1/`

راجع [Webhooks](/docs/api/webhooks) و[الشركات](/docs/api/companies) لتفصيل ما
هو متاح بديلاً.
